# dev-notes — 踩坑记录（顺手就写）

> 目的：**专门放「会话里实际踩到的坑」**，按问题/主题一条一记，遇到就写，
> 不必等你问。用途：给未来的 AI / 自己快速定位**为什么这里会这样**。
>
> 与其它文档的关系：
> - `docs/dev-playbook.md` = **防重复踩坑的浓缩速查**（更短、更稳、先读它）；
> - `docs/iteration-plan.md` = **迭代轮次的事实记录/验证结论**；
> - `docs/android-build.md` 等 = 单主题**唯一真源**；
> - **本目录 `dev-notes/`** = 上面的「原料库」：**具体问题 + 排查过程 + 最终根因**。
>   每一步踩坑都在这里留一手，然后**把它归纳进 dev-playbook**（避免只在这里沉底）。
>
> **命名**：`YYYY-MM-DD-<主题连写>.md`。**索引**：在 `README.md`（本文件）追加一行。
